# Envio de planilhas por e-mail

O modal envia pela conta SMTP configurada no Inventarium, sem conectar o Gmail pessoal.
O destinatário inicia com o e-mail do usuário logado e pode ser alterado.
Assunto e descrição são preenchidos no modal.
O download Excel usa o nome atual do inventário.
O modal permanece aberto quando a API retorna erro.
