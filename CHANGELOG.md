# Changelog

Todas as mudancas relevantes do Inventarium serao documentadas neste arquivo.

O projeto segue Conventional Commits e usa Release Please para preparar pull requests de release, atualizar este changelog, criar tags e publicar GitHub Releases.

## [0.1.0] - 2026-09-08

### Added

- Estrutura de monorepo com backend, frontend web, mobile e documentacao.
- Configuracao inicial de qualidade com Husky, Commitlint, lint-staged e Secretlint.
- Workflows de GitHub Actions para verificacao de qualidade e publicacao da wiki.
- Documentacao arquitetural C4 de contexto, containers e componentes.
- Documento de modelagem de dados.
- Architecture Decision Records em `docs/architecture/adr`.
- Login com Google no frontend web e validacao do ID token no backend.
